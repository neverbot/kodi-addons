neverbot's Kodi add-ons

A small Kodi add-on repository. Install the repository add-on once, then get every add-on listed below (and updates to them) automatically.

Install

  1. Download the repository add-on zip.
  2. In Kodi: Settings → Add-ons → Install from zip file → pick the file. Enable “Unknown sources” first if Kodi asks.
  3. Then: Settings → Add-ons → Install from repository → neverbot's Kodi add-ons → install whichever add-ons you want.
